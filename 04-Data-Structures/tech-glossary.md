🏛️ Tech Glossary 2026 - Foundation Kit
1. Web Standards
Semantic HTML: The practice of using HTML tags according to their intended functional meaning (e.g., <header>, <main>) to enhance web accessibility and Search Engine Optimization (SEO).

CSS Variables: Also known as Custom Properties; these allow you to store specific values (such as --primary-color) to be reused throughout a document, making global design updates easy to manage.

DOM (Document Object Model): A programming interface for web documents that represents the page structure as a logical tree, allowing JavaScript to dynamically access and update the content, structure, and style.

2. Data & Logic
JSON (JavaScript Object Notation): A lightweight, text-based data interchange format that is easy for humans to read and write, and easy for machines to parse and generate.

Local Storage: A web storage mechanism that allows data to be saved locally within the user's browser, enabling applications to function or persist data while offline.

UUID (Universally Unique Identifier): A standardized 128-bit number used to uniquely identify information (such as User IDs) across computer systems without needing a central coordinator.

3. System & Mobile
Bash Script: A plain text file containing a series of commands designed to automate tasks within Linux or Unix-based operating systems.

Android Manifest: An essential XML file in Android development that declares the application's identity, components, and required system permissions (e.g., camera or internet access).

Root Directory: The top-level directory in a file system or project structure, serving as the starting point for all other folders and files.
